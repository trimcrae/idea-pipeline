# Probe kit — watch-authenticity-check: Pre-purchase authenticity / serial-sanity check for used luxury watches

**Status: DRAFT. Nothing here is live.** Model drafts; operator ships (D3/D4).
**Inbound only — no cold outreach** (doctrine #7). See `BACKLOG.md` → watch-authenticity-check.

## What the probe tests
One question: **before wiring real money for a used watch, will a buyer give an
email for a 60-second reference/serial/photo sanity check?** Buyers already
search "how to spot a fake [brand]" — this tests whether that intent converts.

## Pick ONE brand for v1
Reference data is brand-specific; ship one brand first (the placeholder below is
**[Rolex]**). Pick the brand with the most public/community reference data and
the highest fake rate.

## Pass bar (SET — do not move)
**≥10 self-serve sign-ups** from one watch-community post and/or a small ad,
~one week. Below that = no signal → reshape, log, move.

(`maint:manual`); forums and some apps partially serve this. The wedge is the
60-second pre-wire gate for **one brand first**, not a universal authenticator.
